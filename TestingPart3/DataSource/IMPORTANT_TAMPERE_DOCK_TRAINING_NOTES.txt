RANDOM 60/20/20 SPLIT AND THE MEANING OF INDEPENDENCE
The user requested a random split after the initial recording split proposal.
Method: random_images. Seed 4022 shuffles the sorted list of 200 source images
with Python random.Random, assigns 120 train, 40 validation, 40 test, and sorts
each role's membership for stable iteration. This assignment is generated ONCE
per experiment and reused for every LR trial, validation and final test.
Exact membership is saved in resolved_splits.json and resolved_experiment.yaml.
Every source image is assigned once. Image paths and mask paths cannot overlap
between roles. SHA-256 hashes reject identical image bytes crossing roles.
All checks passed for the real dock dataset; split_audit.json stores this audit.
Training batch order is shuffled within the fixed training subset each epoch.

Independence here is FILE-LEVEL separation. No trip IDs or exact recording
boundaries exist in the available dock metadata. Different files can be adjacent
frames or share a scene, so statistical/recording independence is NOT verified.
Results describe held-out random dock frames from the same source collection;
they cannot establish generalization to unseen trips or a separate dock domain.
No visual-similarity grouping or temporal exclusion gap is applied. A future
recording-level study must use verified trip IDs and a new experiment directory.
Optional recording_sequence CSV support remains available in the runner, but is
not active in this user-requested random-image experiment.

MODEL AND FROZEN STATE
Initialize every trial independently from the original non-IMU checkpoint:
TestingPart1/eWaSR/Pretrained/ewasr_resnet18_mlx.npz
The existing decoder.seg_head is retained, not reinitialized. Only its two
convolutions and BatchNorm affine weight/bias receive gradients. ResNet-18,
MetaFormer refinement, SIM fusion and all their BatchNorm affine parameters
remain frozen. Frozen BatchNorm layers stay in evaluation mode and do not
update running statistics. Head BatchNorm uses training statistics and updates
its running mean/variance as non-gradient state; it uses evaluation statistics
for validation/test. The checkpoint contains the full model despite the
best_head_only.npz/latest_head_only.npz filenames.
Earlier channel, port and LaRS experiments are not used as initial weights.

PREPROCESSING AND TRAINING
RGB input: width 512, height 384; bilinear resize from native 1920x1080.
This resize changes the source aspect ratio, matching the existing trainer.
Input scaled to [0,1], then ImageNet normalization:
mean=(0.485,0.456,0.406), std=(0.229,0.224,0.225).
Loss targets: width 128, height 96, nearest-neighbour directly from raw masks.
No 5% reflection padding is applied during eWaSR training; it was part of SAM3
pseudo-label generation, whose saved masks were cropped to the source size.
Optimizer AdamW, initial LR 1e-3; independent LR trials 3e-4, 1e-3, 3e-3.
Weight decay 1e-4; batch size 2; 10 epochs per trial; seed 4022.
Standard unweighted per-pixel cross-entropy. Constant LR; no scheduler,
augmentation, early stopping or backbone fine-tuning in this first attempt.

SELECTION, EVALUATION AND ARTIFACTS
Best epoch for each trial: maximum validation three-class mean IoU.
Chosen LR: highest best validation mean IoU among the three independent trials.
Test data are evaluated only for the pretrained baseline and selected model
after selection; test scores do not select an epoch or LR.
Metrics in this trainer are computed at 128x96 head resolution. They are not
directly comparable to the earlier native-resolution 200-image evaluation
(global mIoU 0.723021), which also included potential future training images.
Compare baseline and adapted model on the SAME held-out split and resolution.
All three-class validation/test scores measure agreement with SAM3 pseudo
labels. The dataset's original binary water masks cannot independently validate
the obstacle-versus-sky separation. Independent human three-class annotations
are needed for claims about true three-class segmentation performance.
