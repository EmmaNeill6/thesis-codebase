SAME PARAMETERS AS THE DOCK EXPERIMENT
Pretrained non-IMU ResNet-18 eWaSR MLX checkpoint:
TestingPart1/eWaSR/Pretrained/ewasr_resnet18_mlx.npz.
Each LR trial starts afresh from this file, not the fine-tuned dock checkpoint
or any earlier channel checkpoint. Retain the existing decoder.seg_head.
Train ONLY its six convolution and BatchNorm affine tensors (67,075 parameters).
Freeze the backbone, MetaFormer refinement, SIM fusion, and their BatchNorm
parameters and running state. Head BatchNorm running mean/variance update as
non-gradient state during training; evaluation uses running statistics.
RGB inputs: width 512, height 384, bilinear resize; normalization after /255:
ImageNet mean [0.485,0.456,0.406], std [0.229,0.224,0.225].
Loss masks: width 128, height 96, nearest-neighbour resize.
AdamW, weight decay 1e-4; initial LR 1e-3; compare 3e-4, 1e-3, 3e-3.
Batch size 2; 10 epochs per trial (30 epochs total); seed 4022.
Standard unweighted cross-entropy, no ignored labels, constant learning rates.
No augmentation, scheduler, early stopping, or backbone training.

SPLIT AND THE MEANING OF INDEPENDENCE
Reuse dock's random_image_splits and audit_split_independence implementation.
Python random.Random(4022) shuffles sorted samples once; assign 120 train,
40 validation, 40 test, then sort each role for stable iteration. Every trial
uses the same membership; only training minibatch order changes each epoch.
Record exact membership in resolved_splits.json and resolved_experiment.yaml.
Check image-path/mask-path overlap and exact image-byte SHA-256 duplicates
across roles. Random frames from the same collection may be nearby frames
sharing scene content; file-level separation does not prove independence of
recordings or generalization to an unseen trip. No trip grouping or exclusion
gap is applied, matching the approved dock random-image method.

CHECKPOINT SELECTION AND EVALUATION
Best checkpoint per LR: maximum validation three-class mean IoU.
Select LR by its best validation mean IoU, then compare only the selected
checkpoint and original pretrained baseline on the held-out channel test set.
The 40 test images do not choose an LR or epoch.
Training-run metrics are aggregate pixel metrics at 128x96 head resolution.
They measure agreement with SAM3 pseudo labels, not independent human truth.
Native-resolution inference/evaluation can differ and is not part of this run.
Original binary dataset masks cannot independently score obstacle versus sky.
Do not use test results to revise hyperparameters on this same test set.

ARTIFACTS

best_head_only.npz and latest_head_only.npz. These are full-model checkpoints;

resolved_splits.json, resolved_experiment.yaml and split_audit.json.
selected_model.json, experiment_results.json, experiment_summary.txt.
frozen_parameter_verification.json: all six saved checkpoints compared with
the original pretrained file; only head tensors/state may change. All 30
epochs and best-validation checkpoint selection are checked after training.
Use resolved_experiment.yaml with visualization tools so they use the exact
random test membership rather than regenerate a different split.
